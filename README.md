# 🎵 Mutown Grooove · 一贴就听

手机贴一下 NFC 挂件 → 直接打开播放器 → 十首歌，想听哪首听哪首。

**网址**：<https://maomao1ovo1.github.io/nfc-tap-9f3a/>

---

## 怎么用

| 你想干嘛 | 怎么做 |
|---|---|
| 打开播放器 | 手机贴一下 NFC 挂件（或直接打开上面的网址） |
| 播放 / 暂停 | 点中间那个大圆钮 |
| 换歌 | 点 ◀ / ▶，或者点底部「☰ 播放列表」自己挑 |
| 拖进度 | 按住进度条拖，**松手才跳**（拖着的时候不加载，所以不卡） |
| 换播放模式 | 点底部那个模式标签 → 弹出菜单直接选 |
| 存到手机（离线听） | 打开播放列表，点每首右边的 **⬇** |
| 锁屏 / 耳机控制 | 锁屏和通知栏直接就有，蓝牙耳机按键也能用 |

## 播放模式

| 模式 | 行为 |
|---|---|
| ➡️ 顺序播放 | 一首接一首，最后一首放完就停 |
| 🔁 列表循环 | 放完最后一首回到第一首，一直转 |
| 🔂 单曲循环 | 这一首反复放 |
| 🔀 随机播放 | 随机挑下一首 |

## 播放列表里的三个小图标

| 图标 | 意思 |
|---|---|
| ⬇ | 还没存到手机 |
| ◐ 橙色 | 只存了一部分 —— **再点一次会接着补**，已经存好的不会重下 |
| ✓ 青色 | 完整存好了，**断网也能听** |

## 它长什么样

- **圆形封面**，播放时慢慢转；暂停就停在原地，**切歌接着转、不会跳回原点**
- 歌名 + 歌手 + 专辑名
- 可拖的进度条（当前时间 / 总时长）
- 底部两个按钮：**当前播放模式**、**播放列表**
- 刷新或重开页面，会回到上一次听的那首、那个位置

## 它是怎么工作的

```
手机（贴 NFC 挂件）
  └─ 打开网页 ──────────────► GitHub Pages（只放页面代码，公开）
                                 │
                                 │ 播放时，向代理要音频
                                 ▼
                          Cloudflare Worker（中间人）
                                 │  验明身份后，才给一小片音频
                                 ▼
                          GitHub 私有仓库（真正的音频，外人无权访问）
```

音频被切成 **10 秒一片**，一首 20–26 片，播一片、准备下一片 —— 所以网快就很顺，网慢会卡（这是流媒体的天性，不是坏了）。

## 那些「踩过坑才改对」的细节

- **进度条松手才跳**：拖动时只更新界面，不然边拖边加载会卡死
- **切歌不转回原点**：封面旋转用常驻动画 + 暂停开关，不是每次重新开始
- **刷新回到原处**：正在听哪首、听到第几秒，都存在手机本地
- **名字和声音是对得上的**：切片当初是按文件名字典序生成的（`1 → 10 → 2 → 3 …`，`10` 排在 `1` 后面），所以每首歌对应的切片编号是**写死的**，不能按顺序推算
- **切歌时锁屏卡片会闪一下**：网页播放器的通病 —— 换音源的瞬间系统会重建卡片，网页侧管不了（别的网站也一样）

## 想自己改

| 改什么 | 动哪里 |
|---|---|
| 歌名 / 歌手 | `index.html` 里的 `TRACKS` 数组（**`n` 是切片编号，别乱动**） |
| 配色 | `index.html` 顶部的 CSS 变量（`--pink` / `--purple` / `--cyan`） |
| 换封面 | 直接替换 `cover.jpg` |
| 换播放内核 | 替换 `hls.min.js` |

改完推上去：

```bash
git add -A && git commit -m "改了什么" && git push
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 播放器本体（界面 + 逻辑，全在这一个文件里） |
| `hls.min.js` | HLS 播放内核，**本地放一份**，不依赖外部 CDN（CDN 加载失败就没声音） |
| `sw.js` | Service Worker：网络优先，断网时回落缓存 |
| `cover.jpg` | 专辑封面 |

## 安全说明（别人能听，但拿不走）

| 防线 | 挡什么 |
|---|---|
| 票据 | 30 分钟有效，只发给「从本页点进来的人」 |
| 每首歌单独签名 | 有票据 ≠ 有音频，还得对得上这首歌的签名 |
| 来源校验 | 不是从本页发起的请求，一律挡掉 |
| 身份黑名单 | wget / curl / python 这类下载器直接 403 |
| **本地加密缓存** | 存到手机的那份是 **AES-GCM 256** 加密的，密钥**不可导出** —— 数据被抄走就是一堆乱码 |

> 一句话：**别人能听，但扒不走文件。**
